# Skill icon sources

Original SVG logos are stored locally without changes to their paths, fills, or proportions. These names and logos identify tools in the portfolio, and remain the property of their respective owners.

- Devicon original variants: https://github.com/devicons/devicon — MIT notice in LICENSE.devicon.txt.
- Power BI: https://github.com/microsoft/PowerBI-Icons — Microsoft artwork and CC BY 4.0 notice in LICENSE.power-bi.txt.
- GitHub white Invertocat: https://brand.github.com/foundations/logo — original SVG from the official logo archive.
- See sources.json for exact pinned URLs, archive entry, and SHA-256 digests.
- Conceptual skills use the existing Lucide React package. Git & GitHub is represented by the two separate original marks.
- Python, Node.js and Supabase use the original Devicon artwork with native brand colors. Express.js uses Lucide's server icon, as permitted for the framework, to remain legible on the dark surface without recoloring a logo.
